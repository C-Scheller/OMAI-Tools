OMAI · Task 1

Allocation planning at AIP Inc.

AIP Inc. builds five battery-electric models in five European plants. Today every plant builds exactly one model. Evaluate allocation proposals for the next planning year with the allocation planning model from the lecture.

Set product–plant links, enter production quantities and check them against the constraints of the model. Choose the scenario and the efficiency loss factor A below. All quantities are in thousand vehicles per year.

    Rules of the case
  1. The current links stay in place and cannot be removed.
  2. Every link that is set up counts as an allocation (fij = 1), even if nothing is produced on it. Each additional link of a plant reduces its capacity by A · Uj.
  3. Production quantities are whole numbers of thousand vehicles.

          The tool checks and optimizes exactly this formulation.

          (O)max Σi∈I Σj∈J xij (1.1)fij ≥ xij / BigM∀ i, j (1.2)Σi∈I fij ≤ Nj + pj∀ j (2)xij ≤ Cij · BigM∀ i, j (3)Σj∈J xij ≥ Mi∀ i (4)Σj∈J xij ≤ Di∀ i (5)Σi∈I xij ≤ Uj − pj · A · Uj∀ j (6)xij ∈ ℕ0; fij ∈ {0,1}; pj ∈ ℕ0∀ i, j
          Sets
          i ∈ I
          models (City, Compact, Sedan, SUV, Van)
          j ∈ J
          plants (A, B, C, D, E)
          Parameters
          Uj
          initial capacity of plant j
          Nj
          initial number of models of plant j (here 1 for every plant)
          A
          relative efficiency loss per additional link
          Cij
          1, if model i can be produced in plant j; 0, else
          Di, Mi
          forecasted demand and minimum demand fulfilment of model i
          Decision variables
          xij
          production quantity of model i in plant j
          fij
          1, if model i is allocated to plant j (link)
          pj
          number of additional links of plant j
